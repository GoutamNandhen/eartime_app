# Project State

EarTime is an Android-first, local listening-observation application with a
Flutter interface. The approved 119-feature roadmap is tracked in
[FEATURE_MATRIX.md](FEATURE_MATRIX.md); a row marked IN_PROGRESS is not a
completion claim.

Native journal/projection integration, consumer cutover, a native multi-device
widget and persistent settings have automated evidence. Real route attribution,
validated collector liveness, evidence-backed physical identity, telemetry,
full data controls and final release acceptance are unfinished.

`0a8be43` remains the known-good G reference and the protected service is
unchanged. Current physical G is not validated. See [Current State](CURRENT_STATE.md),
[Resume](CODEX_RESUME.md) and [Release Validation](RELEASE_VALIDATION.md).
